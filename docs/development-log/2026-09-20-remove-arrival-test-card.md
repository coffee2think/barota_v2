# 2026-09-20 — 도착 화면 테스트용 열차 카드 제거

## 1. 배경 / 문제

디버그 빌드의 실시간 도착 화면에 정차·미정차 색상을 수동으로 확인하기 위한 테스트 컨트롤과 가짜 열차 카드가 항상 노출됐다. 실제 조회 결과와 관계없는 카드이므로 사용자 화면에서 제거할 필요가 있었다.

## 2. 결정 및 이유

테스트 카드만 숨기는 조건을 추가하지 않고, 가짜 열차 데이터와 상태 덮어쓰기 기능 전체를 제거했다. 자동화 테스트는 실제 `ArrivalUiState.arrivals`에 테스트 데이터를 전달해 카드 색상과 표시 순서를 검증할 수 있으므로 런타임 테스트 UI가 필요하지 않다.

## 3. 구현 내용

* `ArrivalScreen`의 테스트 상태, 정차 여부 테스트 버튼, 테스트용 열차 제목과 가짜 카드를 제거했다.
* 실제 열차 카드와 화면 배경은 `TrainArrival.destinationStopStatus`만 사용하도록 단순화했다.
* 디버그 진단에서 테스트 미리보기가 실제 판정을 덮어썼다는 표시를 제거했다.
* Compose 테스트가 전달한 실제 도착 목록과 같은 수의 카드만 렌더링되는지 검증하도록 변경했다.
