# 2026-09-20 — 현재 개발 현황 리포트 작성

## 1. 배경 / 문제

사용자가 이후 MVP 개발의 우선순위를 판단할 수 있도록, 현재 화면·데이터 흐름·핵심 기능의 구현 및 검증 범위를 한 번에 확인할 수 있는 자료를 요청했다. 기존 기록은 기능별로 분산되어 있었고, 목적지 정차 판정의 이전 평가에는 그래프 확장 전 제약이 포함되어 있었다.

## 2. 결정 및 이유

현재 코드와 최근 자동 검증 결과를 기준으로 별도 현황 리포트를 작성했다. 기능 존재 여부와 운영 신뢰성은 같은 의미가 아니므로 `[x]` 구현·자동 테스트, `[~]` 제한 또는 실제 API 검증 필요, `[ ]` 미구현으로 구분했다.

## 3. 구현 내용

* `docs/reports/2026-09-20-current-development-status.md`에 화면, 데이터 흐름, 도메인·저장소 기능, MVP 체크표, 제약, 다음 개발 권장 순서를 정리했다.
* 1~9호선 방향 그래프 확장 이후 상태를 반영하고, 시간표 API 호환성·2호선 순환 방향 선택·실기기 검증이 남았음을 명시했다.

## 4. 검증 결과

* 리포트의 구현 상태는 현재 소스와 자동 테스트를 기준으로 작성했다. 이후 제한 하드코딩 제거 작업까지 반영한 현재 기준은 JVM 단위 테스트 54개 성공, Android Compose 테스트 컴파일 성공, Lint 오류 0이다.
* 리포트 작성 자체는 런타임 동작을 변경하지 않았다.

## 5. 남은 작업 / 보류 사항

* 리포트에 제시한 2호선 순환선 방향 선택과 실제 시간표 API 계약 검증의 우선순위는 사용자의 제품 정책 결정에 따라 조정한다.
