# 2026-10-01 Gradle 빌드 성능 설정 정리

## 1. 배경 / 문제

- 작업 트리에 Gradle의 병렬 처리와 구성 캐시 관련 설정 변경이 존재해 커밋 단위를 명확히 정리할 필요가 있었다.

## 2. 검토한 선택지

- 기존 병렬 실행과 빌드 캐시 설정만 유지하는 방법을 검토했다.
- Tooling API 병렬 처리와 구성 캐시를 함께 명시하는 현재 변경을 유지하는 방법을 검토했다.

## 3. 결정 및 이유

- 현재 작업 트리에 있던 `org.gradle.tooling.parallel`과 `org.gradle.configuration-cache` 설정을 유지한다.
- Gradle JVM 자동 다운로드 설정은 이 성능 설정과 별개이고 도입 의도가 확인되지 않아 포함하지 않는다.

## 4. 구현 내용

- `gradle.properties`의 설정을 Gradle JVM, 빌드 성능, Android 항목으로 구분했다.
- Tooling API 병렬 처리와 구성 캐시를 활성화했다.

## 5. 검증 결과

- `git diff --check`로 공백 오류 여부만 확인했다.
- 사용자 요청 범위에 따라 테스트, Lint와 빌드는 실행하지 않았다.

## 6. 남은 작업 / 보류 사항

- 구성 캐시와 호환되지 않는 작업이 확인되면 해당 설정을 재검토한다.
