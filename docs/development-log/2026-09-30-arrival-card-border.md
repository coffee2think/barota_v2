# 열차 카드 경계 가시성 개선

## 1. 배경 / 문제

도착정보 화면은 가장 가까운 열차의 목적지 정차 상태에 따라 화면 배경을 초록색 또는 빨간색으로 바꾸고, 해당 열차 카드에도 같은 배경색을 사용한다. 기존 열차 카드에는 테두리가 없어 화면과 카드의 배경색이 같을 때 카드 경계를 구분하기 어려웠다.

## 2. 검토한 선택지

* 화면과 카드 배경색이 같을 때만 테두리를 표시하면 필요한 경우에만 경계를 만들 수 있지만, 열차 상태와 목록 위치에 따라 카드 외형이 달라진다.
* 정차 상태별 강조색 테두리는 상태 의미를 강화하지만 색상 의존성과 시각적 자극이 커진다.
* 모든 열차 카드에 테마의 중립색 테두리를 적용하면 상태와 배경 조합에 관계없이 일관된 경계를 제공할 수 있다.

## 3. 결정 및 이유

모든 열차 카드에 `1.dp` 두께의 `MaterialTheme.colorScheme.outline` 테두리를 적용했다. Material 테마의 중립색을 사용하면 라이트, 다크 및 동적 색상 환경에 맞춰 색상이 결정되고, 정차 상태별 배경색이나 빨간색 점멸 의미를 추가 색상으로 방해하지 않는다.

테두리는 열차 카드의 경계 문제만 해결하도록 `ArrivalCard`에 한정했다. 경로 헤더와 오류 안내 카드의 외형은 변경하지 않았다.

## 4. 구현 내용

* 열차 카드의 Material 3 `Card`에 `BorderStroke(1.dp, MaterialTheme.colorScheme.outline)`을 추가했다.
* `STOPS`, `DOES_NOT_STOP`, `UNKNOWN` 상태에 동일한 고정 테두리가 표시된다.
* 기존 카드 모양, 내부 여백, 상태별 배경색, 화면 배경 동기화와 빨간색 점멸 애니메이션은 유지했다.
* 데이터 모델, ViewModel, API와 공개 Composable 인터페이스는 변경하지 않았다.

## 5. 검증 결과

* `testDebugUnitTest`: 65개 성공, 실패 0, 오류 0, 건너뜀 0.
* `compileDebugAndroidTestKotlin`: 성공.
* 빌드 환경에서 Android 분석 설정과 Kotlin 데몬 임시 파일의 기본 사용자 경로에 접근하지 못한다는 메시지가 출력됐지만, 프로젝트 내부 Gradle 및 Android 사용자 디렉터리를 사용한 최종 빌드는 성공했다.
* 실제 기기 또는 에뮬레이터에서 카드 경계의 시각적 대비는 확인하지 못했다.

## 6. 남은 작업 / 보류 사항

* 라이트·다크 테마와 동적 색상 환경에서 초록, 빨강 점멸, 기본 상태 카드의 테두리 대비를 실제 화면으로 확인한다.
* 빨간색 점멸의 양 끝 색상에서도 테두리가 안정적으로 식별되는지 확인한다.
