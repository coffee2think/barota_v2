# 2026-09-18 — 실기기 진입 열차 문제에 대한 MVP 수정 계획

## 1. 배경 / 문제

사용자 스마트폰 테스트에서 진행 방향과 무관한 열차 노출, 진입 순서 오류, 정차 여부 색상 표시 문제가 보고되었다. 독산역 누락과 선로 장애 지연 안내 요구도 있었지만 최신 역 데이터와 공지 API는 추후 제공 예정이므로 사용자가 이번 작업에서 제외했다.

## 2. 검토한 선택지

- 다섯 문제를 함께 구현하는 계획: 추가 데이터/API에 의존하며 사용자가 지정한 범위를 벗어난다.
- 1~3번을 기존 구조에서 수정하고 나머지를 보류하는 계획: 외부 자료 제공을 기다리지 않고 핵심 MVP 개선을 추진할 수 있다.
- 방향 추정에 현재 역 목록 순서 또는 정차 결과 사용: 역 목록에는 진행 순서가 없고 미정차/매칭 실패가 방향과 혼동되므로 부적절하다.
- 별도 최소 방향 기준 및 판정기 도입: 전체 역 갱신과 분리하고 검증 가능한 경로부터 지원할 수 있다.

## 3. 결정 및 이유

1~3번만 MVP 수정 범위로 계획했다. 방향 필터와 정렬을 정차 판정 이전에 적용하고 최종 첫 열차와 화면 배경을 일치시키기로 했다. 방향 근거가 없는 경로는 무필터 결과로 대체하지 않는다. 색상 분기는 이미 존재하므로 실제 정차 데이터 전달 및 확인 불가 원인을 먼저 진단한다. 불완전 시간표를 미정차로 오인하지 않는 조건과 실제 데이터를 덮어쓰는 디버그 UI 분리도 계획에 포함했다.

- `docs/plans/2026-09-18-arrival-mvp-fix-tasks.md`: T01~T08 작업, 의존성, 관련 코드, 완료 기준.
- 앱 코드와 역 데이터는 수정하지 않았다. 실제 문제 수정은 아직 수행하지 않았다.

## 5. 검증 결과

실시간 Repository, 시간표 Repository, DTO, 도메인 모델, 역 데이터 구조, ViewModel, Compose 화면 및 기존 테스트를 정적으로 확인했다. 방향 필터 부재와 노선/방향 우선 정렬을 확인했다. 실제 키·API 응답·앱 실행·자동 테스트·실기기 수정 후 검증은 수행하지 않았다. 문서 작성은 구현 완료 또는 테스트 통과를 뜻하지 않는다.

## 6. 남은 작업 / 보류 사항

태스크 문서 순서로 재현 자료와 방향 지원 근거를 확보한 뒤 구현한다. 최신 역 정보/독산역 반영과 공지 API/노란 지연 공지 카드는 사용자 자료 제공 후 별도 계획한다. 기존 기록은 변경하지 않았다.
