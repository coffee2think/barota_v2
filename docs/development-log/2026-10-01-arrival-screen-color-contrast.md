# 도착 정보 결과 화면 색상 대비 개선

## 1. 배경 / 문제

목적지 정차 여부에 따라 도착 정보 결과 화면 배경이 밝은 초록색 또는 점멸하는 빨간색으로 바뀌지만, 상단 앱 바의 제목과 아이콘은 테마 기본 전경색을 사용했다. 다크 테마나 동적 색상 환경에서는 밝은 상태 배경 위에 흰색 전경이 적용될 수 있어 가독성이 낮았다.

또한 열차 카드가 화면과 같은 상태 배경색을 사용해 카드와 화면의 경계가 테두리에만 의존했고, 열차 정보가 충분히 도드라지지 않았다.

## 2. 검토한 선택지

* 상단 앱 바에 항상 검정색을 적용하는 방법은 단순하지만, 정차 여부 확인 전의 기본 화면과 다크 테마에서 대비가 맞지 않을 수 있다.
* 카드에 그림자만 추가하는 방법은 화면과 카드의 색상 위계를 직접 해결하지 못한다.
* 기존 열차 카드와 정보 칩처럼 상태별 전경색을 명시하고, 화면과 카드에 같은 계열의 서로 다른 명도를 사용하면 의미와 통일성을 함께 유지할 수 있다.

## 3. 결정 및 이유

상단 앱 바의 제목, 뒤로가기 아이콘, 새로고침 아이콘에 화면 상태별 전경색을 명시한다. 정차 상태는 진한 초록색, 미정차 상태는 진한 빨간색, 확인 전 상태는 테마의 `onBackground`를 사용해 기존 열차 카드의 전경색 규칙과 통일했다.

열차 카드는 화면 상태 배경보다 진한 같은 계열의 색상을 사용한다. 미정차 상태의 점멸 동작은 유지하되 화면용과 카드용 점멸 색상을 분리해 모든 점멸 단계에서 카드가 더 도드라지도록 했다.

## 4. 구현 내용

* `TopAppBarDefaults.topAppBarColors`에 상태별 제목 및 내비게이션·액션 아이콘 전경색을 지정했다.
* 정차 카드 배경을 화면의 연한 초록색보다 진한 초록색으로 변경했다.
* 미정차 카드에 화면 점멸 배경보다 진한 별도 빨간색 점멸 애니메이션을 적용했다.
* 출발·도착 노선 요약 카드는 `onPrimaryContainer`를 명시해 컨테이너 배경과의 테마 대비를 유지했다.
