# 열차 카드 디버그 정보 제거

## 1. 배경 / 문제

목적지 정차 판정 검증을 위해 열차 카드에 노선, 판정 사유, 시간표 매칭 수, K/S 열차번호 및 도착 원시 상태를 표시하고 있었다. 정차·미정차 판정이 정상 동작하게 되어 사용자 화면에서는 내부 진단 정보가 더 이상 필요하지 않다.

## 2. 결정 및 이유

열차 카드의 디버그 UI만 제거한다. 정차 판정 상태와 진단 데이터 모델은 장애 분석 및 테스트에 계속 필요하므로 유지한다.

## 3. 구현 내용

* 디버그 빌드에서만 출력하던 `ArrivalDebugInfo`와 관련 문자열 변환 함수를 제거했다.
* `BuildConfig.DEBUG` 기반 디버그 영역을 열차 카드에서 제거했다.
* 정차/미정차 안내 문구, 초록/빨강 카드 표시, 종착역 및 열차 종류 정보는 유지했다.
* UI 테스트는 내부 진단 문자열이 화면에 노출되지 않는지 확인하도록 변경했다.

## 4. 검증 결과

* `gradlew testDebugUnitTest --no-daemon`: 성공, 59개 단위 테스트 통과
* `gradlew compileDebugAndroidTestKotlin lintDebug assembleDebug --no-daemon`: 성공
* UI 테스트에서 노선 진단, 실제 판정, 시간표 매칭, 시간표 열차번호, 도착 데이터 문자열이 노출되지 않음을 검증하도록 변경했다.
