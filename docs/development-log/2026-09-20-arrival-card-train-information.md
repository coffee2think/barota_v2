# 열차 카드 운행 정보 가독성 개선

## 1. 배경 / 문제

실시간 도착정보의 열차 카드는 도착 예정시간과 방향, 행선지 등을 보여 주고 있었지만 `btrainNo`가 화면에 표시되지 않았다. 목적지 정차 판정과 열차번호 매핑을 실제 데이터와 대조할 때 사용자가 어떤 열차인지 직접 확인하기 어려웠다. 또한 현재 위치와 일반/급행 구분은 데이터가 있어도 라벨이 없거나 일반열차인 경우 생략되어 의미가 명확하지 않았다.

## 2. 검토한 선택지

* 열차번호만 기존 칩 영역에 추가하면 변경은 작지만 행선지가 긴 카드에서 한 줄이 넘치고 핵심 식별 정보가 눈에 잘 띄지 않는다.
* 열차번호를 카드 상단의 노선·방향 영역에 고정하고, 부가 운행 정보는 여러 줄로 흐를 수 있는 칩 영역에 배치하면 정보 우선순위와 작은 화면 대응이 더 명확하다.

## 3. 결정 및 이유

열차번호는 노선 및 방향과 같은 식별 정보이므로 카드 상단 우측에 `열차번호` 라벨과 함께 고정 표시한다. 행선지, 열차 종류, 막차 여부는 `FlowRow` 칩으로 구성하여 화면 폭이 좁거나 행선지 이름이 긴 경우 다음 줄로 자연스럽게 배치한다.

## 4. 구현 내용

* 열차번호를 고정폭 글꼴과 굵은 글씨로 표시했다.
* 열차번호 텍스트에 `arrival-train-number` 테스트 태그를 추가했다.
* 현재 위치를 `현재 위치 · ...` 형식으로 명확하게 표시했다.
* 행선지 칩을 `행선지 ...행` 형식으로 변경했다.
* 급행뿐 아니라 일반열차도 `열차 종류 일반`처럼 표시한다.
* 목적지 정차 판정이 끝나지 않은 카드는 `목적지 정차 여부 확인 중`이라는 사용자용 상태를 표시한다.
* 긴 행선지와 여러 칩이 카드 폭을 넘지 않도록 칩 컨테이너를 `FlowRow`로 변경했다.

## 5. 검증 결과

`testDebugUnitTest` 전체 실행이 성공했다. 앱 및 Compose 코드 컴파일과 기존 단위 테스트 65개가 모두 통과했다.

실제 기기나 에뮬레이터에서 작은 화면, 시스템 글꼴 확대 상태의 시각 검증은 아직 수행하지 않았다.

## 6. 남은 작업 / 보류 사항

* 실제 기기에서 긴 행선지, 급행, 막차, 열차번호 누락 상태를 각각 확인한다.
* 접근성 글꼴 크기를 크게 설정했을 때 열차번호 상단 영역과 칩 줄바꿈을 확인한다.
