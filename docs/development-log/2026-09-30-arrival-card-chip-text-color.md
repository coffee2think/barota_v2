# 열차 카드 정보 칩 글자색 가독성 개선

## 1. 배경 / 문제

열차 카드 하단의 행선지와 열차 종류 칩이 Material 3의 기본 라벨 색상을 사용해 카드의 초록색, 빨간색 또는 테마 배경 위에서 글자가 선명하게 보이지 않는 경우가 있었다. 카드 본문의 다른 정보는 목적지 정차 상태와 테마에 맞춘 색상을 사용하고 있어 칩과 가독성 차이가 발생했다.

## 2. 검토한 선택지

* 모든 칩 글자를 검정색으로 고정하면 밝은 카드에서는 단순하지만 다크 테마의 기본 카드에서는 대비를 보장할 수 없다.
* 카드가 이미 사용하는 상태별 본문색을 칩에도 적용하면 초록·빨강 카드의 의미를 유지하면서 기본 카드에서는 테마의 `onSurface` 색상으로 대응할 수 있다.

## 3. 결정 및 이유

행선지, 열차 종류와 막차 칩의 라벨 색상을 카드의 `contentColor`로 통일했다. 정차 카드는 진한 초록, 미정차 카드는 진한 빨강, 확인 중 카드는 현재 테마의 `onSurface`를 사용하므로 각 카드 배경과 테마에 맞는 대비를 유지할 수 있다.

## 4. 구현 내용

* `AssistChipDefaults.assistChipColors(labelColor = contentColor)`로 카드별 칩 색상 구성을 생성했다.
* 행선지, 열차 종류와 막차 `AssistChip`에 같은 색상 구성을 적용했다.
* 칩 문구, 배치, 테두리, 카드 배경과 정차 상태 동작은 변경하지 않았다.

## 5. 검증 결과

* `testDebugUnitTest`: 65개 성공, 실패 0, 오류 0, 건너뜀 0.
* `compileDebugAndroidTestKotlin`: 성공.
* 실제 기기 또는 에뮬레이터에서 상태별 칩 글자 대비는 확인하지 못했다.

## 6. 남은 작업 / 보류 사항

* 라이트·다크 및 동적 색상 테마에서 정차, 미정차, 확인 중 카드의 칩 글자 대비를 실제 화면으로 확인한다.
